Set up Import

Pick a folder — mounted inside the container, like anything under /media — to drop new books into. Mochil watches it, copies verified files into its own managed storage, and leaves the originals untouched. You can change the folder here any time.

Books are copied from the drop folder into the managed folder. The originals are never changed or removed. Click a cell to correct it; the saved name updates. Shift-click a checkbox to select a range, or use Space and Shift+Space on the highlighted row.
