Settings

Pick a page. Each one holds a single area, so nothing hides at the bottom of a long list.

Narration

The voices the reader can read aloud with. Make a new one from a short recording.

Narration is off or not installed. Turn it on under Modules to manage voices here.

Diagnostics

Server health at a glance: uptime, memory, slow requests and background errors.

Editor

The library editor is an optional module for administrators: a spreadsheet-like table for books, with Hermes-assisted tools when Hermes is on.

Libraries

Open a library to change it. The switch shows or hides it on this device only.
